# Veikart

Arbeidsplan v0.1. Avkryssede punkter beskriver materiale som finnes i repoet; de betyr ikke juridisk godkjenning eller gjennomført tjenestetest.

## 0. Offentlig startgrunnlag

- [x] Prosjektbeskrivelse med tydelig utviklingsstatus.
- [x] Utkast til protokoll og vurderingsrubrikk.
- [x] Primærkilder og avgrensning mot eksisterende benchmark.
- [x] Bidragsveiledning, rollebeskrivelse og lisens.
- [x] Saksmal og to fiktive utviklingseksempler.

## 1. Faglig avgrensning

- [ ] Kartlegg aktuelle tjenester, produktnivåer og støttede oppgaver.
- [ ] Velg to rettsområder og målgrupper for første pilot.
- [ ] Avklar hvilken tilgang og bruk som tillater evalueringen.
- [ ] Finn juridiske bidragsytere og dokumenter relevante interesser.
- [ ] Bestem en praktisk fordeling av bokmål, nynorsk og språkpar.

## 2. Utviklingssaker og metode

- [ ] Utarbeid totalt 8–12 offentlige utviklingssaker.
- [ ] Kontroller kildegrunnlag, datoer, vilkår og alternative utfall.
- [ ] Prøv rubrikken med to juridiske vurderere og dokumenter uenighet.
- [ ] Juster avklaringsdialog, alvorlig-feil-kriterier og UX-observasjoner.
- [ ] Fastsett protokoll, tidsrammer, gjentakelser og rapportformat før pilot.

## 3. Pilot med 48 sakspakker

- [ ] Opprett separat tilgangsstyrt oppbevaring for skjult evalueringsmateriale.
- [ ] Lag og kontroller sakspakkene; utviklingssakene holdes utenfor.
- [ ] Lag kjørelogg med produkt, abonnement, modus, rettsdato og tidspunkt.
- [ ] Gjennomfør standardiserte kjøringer uten å velge bort svake svar.
- [ ] Gjennomfør juridisk bedømmelse med skjulte leverandørnavn der mulig.
- [ ] Dokumenter tekniske feil, manglende støtte, avvisninger og avvik separat.

## 4. Etterprøvbar rapportering

- [ ] Rapporter kvalitetsprofil, alvorlige feil og separat UX-vurdering.
- [ ] Beregn usikkerhet på saksnivå og forklar utvalgets begrensninger.
- [ ] Avklar grunnlaget for å dele svar, utdrag og referansemateriale.
- [ ] Publiser metode, relevante resultater og en tydelig rettelsesprosess.
- [ ] Vurder videre utvidelse først etter erfaringene fra piloten.

En automatisk testkjører, formelt oppgaveskjema og adaptere til tjenester er mulige senere bidrag. De skal støtte en avklart metode og dokumenterte tilgangsvilkår. Det er ikke satt dato for offentlig rangering.
